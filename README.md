# LEAPスロット単語テスト

LEAP 英単語をスロット・サイコロ・ダービーなどのゲーム要素で楽しく学習できる単語テストアプリです。学習データはブラウザに保存され、ログインすると Firebase（Authentication + Firestore）でクラウドに同期できます。

## 技術構成

- 単一の静的 HTML（`public/index.html`）— HTML / CSS / JavaScript のみ、ビルド不要
- Firebase Authentication（メール/パスワード）と Cloud Firestore（CDN から読み込み）
- SheetJS（xlsx）による単語リストの読み込み
- Netlify で静的ホスティング

## 単語リストの更新

出題する単語は `public/words.txt` から読み込みます。リストを変えるときは、このファイルを新しいものに差し替えてデプロイするだけです。

- 形式は「番号<TAB>英単語<TAB>意味<TAB>例文<TAB>例文の訳」（1行目に `#leapslot v1` の見出し行）。アプリの「txtで書き出す」と同じ形式です。例文・訳の列は空でも構いません。
- 見出し行がない場合も、アプリの「単語を読み込む」と同じく tsv / csv / 「番号 単語 意味」形式を読み取れます。文字コードは UTF-8 と Shift_JIS に対応しています。
- 利用者がアプリを開くと、リストの変更が自動で反映されます。各自が付けた例文と評価値は同じ英単語のものが引き継がれます。
- 利用者が自分でリストを読み込んでいる場合は、自動では切り替わらず「公開リストに切り替える」ボタンが表示されます。
- ファイル名を変える場合は `index.html` 内の `WORDS_URL` を合わせて変更してください。

## ローカルでの確認

```bash
npx serve public
# または
netlify dev
```

ブラウザで表示された URL を開きます。

## 公開

`main` ブランチの内容が Netlify に自動デプロイされます。公開ディレクトリは `public/` です。
